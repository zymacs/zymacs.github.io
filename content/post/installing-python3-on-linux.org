Python comes pre-installed on most Linux distros. But if for whichever
reason it isn't installed on yours, we'll install it in the next
section.

First, let's update and upgrade your system

If you are on Ubuntu, run:

#+begin_example
 sudo apt update && sudo apt upgrade
#+end_example

For Arch, run:

#+begin_example
sudo pacman -Syu
#+end_example

Fedora:

#+begin_example
sudo dnf upgrade
#+end_example

Now let's install python (plus some extra packages you will most
definitely eventually need when using python)

Ubuntu

#+begin_example
sudo apt install python3 python3-pip python3-venv
#+end_example

Arch

#+begin_example
sudo pacman -S python python-pip python-virtualenv
#+end_example

Fedora

#+begin_example
sudo dnf install python3 python3-pip python3-virtualenv python3-devel
#+end_example

Regardless of which distro you are running, confirm python is installed
by running

#+begin_example
python --version
#+end_example

If that command runs successfully (prints out what python version is
installed) then you are ready to run python programs on your system.

Should you face any errors, it surely is the case someone has faced them
before online and they got the answer posted. If that does not help,
please drop your issue in the comment section and someone , including
me, could provide you with assistance.

Hope that helped. Happy Hacking.
