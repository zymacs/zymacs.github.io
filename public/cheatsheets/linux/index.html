10. FILE PERMISSIONS (rwx) & OWNERSHIP

Understanding Formats

  • File Types: -[regular file], d[directory], l[symbolic link]
  • Triad Blocks: Owner (u), Group (g), Others (o), All (a)
  • Value Keys: r = 4 (read), w = 2 (write), x = 1 (execute), - = 0 (no permission)

Numeric Mapping Examples

755
rwxr-xr-x (Full owner control, read/execute access for others)
644
rw-r---- (Read/Write owner privileges, read-only balance)
700
rwx------ (Full owner control isolated from everyone else)

Change Permissions (chmod)

chmod u+x <file>
Add execute permission parameter to owner
chmod g+w <file>
Add write permission tracking to group
chmod o-r <file>
Remove read permissions from others
chmod a+r <file>
Add read permissions to everyone globally
chmod go=r <file>
Hard-set group and others to read-only access
chmod 755 <file>
Explicitly apply 755 permissions
chmod -R 755 <dir>
Recursively change nested directory permissions layout

Change Ownership (chown / chgrp)

chown <user> <file>
Reassign owner of a file
chown <user>:<group> <file>
Reassign both user owner and group owner targets simultaneously
?
chown -R <user>:<group> <dir>:: Recursively cascade ownership over target directory trees
chgrp <group> <file>
Reassign file group parameter
chown –reference=<file1> <file2>
Duplicate permission mappings from file1 onto file2

Special Bits Configuration

SetUID (4)
Executed with target file owner level privilege access. Syntax: chmod u+s <file>
SetGID (2)
Executed with directory/group assigned rights. Syntax: chmod g+s <dir>
Sticky Bit (1)
Only file owners can erase files in target folder. Syntax: chmod +t <dir>

Umask Configs

  • Default security masks for establishing fresh filesystem entries.
  • Files Calculation: 666 - umask = permissions
  • Directories Calc: 777 - umask = permissions
  • 022 (Standard mask) -> Files: 644, Dirs: 755
  • 077 (High restriction) -> Files: 600, Dirs: 700

11. AUTOMATE TASKS: CRON TASKS SCHEDULER

Syntax

Format mapping fields: * * * * * command

  • Field 1: Minute (0-59)
  • Field 2: Hour (0-23)
  • Field 3: Day of month (1-31)
  • Field 4: Month (1-12)
  • Field 5: Day of week (0-7, where 0 and 7 indicate Sunday)

Commands

crontab -e
Edit or configure current user cron registry file
crontab -l
List active schedule tracking automation items
crontab -r
Wipe out all schedule configurations for active user

Execution Example

14. SHELL SCRIPTING FUNDAMENTALS

Core Concepts

Shebang Line
#!/bin/bash (First file line; tells system which interpreter to execute script)
Script Execution
Make executable using chmod +x script.sh, then initiate with ./script.sh

Input & Read Management

read name
Accept standard keyboard string input into variable '$name'
read -p "Enter Age: " age
Prompt interactive user with string message during input sequence
read n1 n2 n3
Gather multiple distinct data variables in sequence via single step

Variables Manipulation

Rules
No spaces allowed around assignments (e.g., msg"Hello"= is valid; msg = "Hello" fails)
Reference Usage
Access variable values by prefixing string with dollar symbol identifier: $msg

Command Substitution

Capture execution outputs directly inside functional operational parameters.

Example 1
date_=$(date)
Example 2
lines=$(wc -l < file.txt)

Arithmetic Actions

Perform math parameters using structural $(( )) wrapping syntax wrappers. No internal spacing required.

Example
sum=$((a + b))

Positional & Command Arguments

$0
File name identity of execution script
$1
First argument input parameter fed to script engine
$2
Second argument input parameter fed to script engine
$#
Integer metric totaling number of arguments supplied to script interface
$@
Array string mapping capturing all argument parameters supplied to script interface
shift
Move positional arguments leftward by one structural index slot ($2 becomes $1)

Script Debugging & Safety Directives

set -e
Halt execution sequence instantly if any script command reports error failures
set -u
Treat unmapped unassigned variables as explicit structural code errors
set -o pipefail
Intercept and report errors tracking mid-stream inside pipe connections
trap 'echo error' ERR
Event listener wrapper to trigger alert routines during error faults
$?
Output exit check status state flag monitored from the last executed statement

Conditionals Syntax Block

Always retain isolated spaces inside evaluation square brackets context layout structures: [ ].

Evaluators
-eq (equal), -ne (not equal), -gt (greater than), -lt (less than)
String Flags
= (equal strings), ! (not equal strings)
if [ "$1" -eq 0 ]; then
    echo "Zero"
elif [ "$1" -gt 0 ]; then
    echo "Positive"
else
    echo "Negative"
fi

Loops Control Loops

For Loops 

for i in 1 2 3 4 5; do
    echo "Number: $i"
done

for file in *.txt; do
    echo "File: $file"
done

While Loops 

count=1
while [ $count -le 5 ]; do
    echo "Count: $count"
    count=$((count+1))
done

Until Loops 

n=1
until [ $n -gt 5 ]; do
    echo "N: $n"
    n=$((n+1))
done
