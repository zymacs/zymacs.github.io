1. FILE & DIRECTORY NAVIGATION Basics

File Basics

ls
List files and directories
ls -l
Long listing format (permissions, owner, size, date)
ls -a
Show hidden files (starting with a dot)
ls -lh
Human-readable sizes (e.g., 4K, 23M)
pwd
Print working directory

Directory Navigation

cd <dir>
Change directory to <dir>
cd ..
Go up one directory level
cd ~
Go to home directory
cd -
Go to previous directory

File Management

mkdir <dir>
Create a new directory
rmdir <dir>
Remove empty directory

2. VIEWING & FILTERING FILE CONTENT

File Content Viewers

cat <file>
Display entire file content
less <file>
View file page by page (scrollable, press 'q' to quit)
more <file>
View file (scroll scroll forward only)
head <file>
Show first 10 lines
?
head -n 20 <file>:: Show first 20 lines
tail <file>
Show last 10 lines
?
tail -n 20 <file>:: Show last 20 lines
tail -f <file>
Follow file updates in real-time (live log tracing)
nl <file>
Number all lines

Content Statistics

wc <file>
Count lines, words, and bytes
wc -l <file>
Count lines only
wc -w <file>
Count words only
wc -c <file>
Count bytes only

File Information

stat <file>
Show detailed file statistics and metadata
file <file>
Determine file/data type
tree <dir>
Show directory tree structure layout
ls -R <dir>
List files recursively
realpath <file>
Show full absolute path

Text Filtering & Search (grep, awk, sed)

grep "pattern" <file>
Search specific pattern in a file
grep -i "pattern" <file>
Ignore case sensitive details
grep -r "pattern" <dir>
Search recursively across directory paths
grep -n "pattern" <file>
Show line numbers alongside results
grep -v "pattern" <file>
Invert match (exclude lines matching pattern)
awk '{print $1}' <file>
Print first column of text data
awk -F: '{print $1}' /etc/passwd
Use ":" as field delimiter
sed -n '1,5p' <file>
Print lines 1 to 5 specifically
sed 's/old/new/g' <file>
Replace all instances of 'old' with 'new'
cut -d: -f1 <file>
Cut columns using custom delimiters
sort <file>
Sort text lines
uniq <file>
Remove duplicate duplicate lines
uniq -c <file>
Count duplicate lines
tr 'a-z' 'A-Z' <file>
Convert text strings from lowercase to UPPERCASE

3. PROCESS & SYSTEM MANAGEMENT

Process Management

ps
Show current active process shell instances
ps aux
All running processes across the active system (detailed layout)
ps -ef
Full system process format listing
top
Real-time interactive process monitor
htop
Enhanced interactive process viewer (highly readable)
pstree
Display processes organized as a visual branch tree
?
pgrep <name>:: Find process ID by its string name
?
pidof <name>:: Show PID of specific running process
kill <PID>
Terminate process gracefully using ID
?
kill -9 <PID>:: Force kill a stubborn process instantly
?
killall <name>:: Kill all active processes belonging to a named software
nice -n 10 <cmd>
Run command with a lower or specific assigned priority
renice 5 <PID>
Change active priority behavior on a live PID

System Information

uname -a
Print all core system architectures and kernel info
uname -r
Output kernel release details
hostname
Display or set system host name
hostname -I
Display local network IP addresses of host
whoami
Show current active user identity
id
Print real user and group IDs
date
Show or configure system date/time parameters
cal
Display an terminal calendar layout
w
See who is logged in and what they are currently doing
last
Show history of last user logins
lastlog
Display last login timestamp statistics per user accounts
uptime
Check how long the host machine has been running continuously
lscpu
View complete CPU technical info specifications
lsmem
View system hardware memory layout segments
dmidecode
Dump system hardware info from BIOS tables
dmesg
Print out kernel ring buffer log errors/messages

Hardware Metrics

lspi
List PCI devices
lsusb
List USB hardware devices
lshw
Detailed list summary of hardware configs

4. DISK USAGE & FILESYSTEM

df -h
Check disk space available across partitions (human-readable)
?
du -sh <dir>:: Show summary size of a specific directory folder path
du -h –max-depth=1
Size of immediate subdirectory trees below target
ncdu <dir>
Interactive disk usage terminal analyzer interface (requires installation)
mount
View mounted filesystems on the server
lsblk -f
Block devices list structure including specific layout mappings
blkid
Fetch individual block device attribute tags (UUIDs, types)
